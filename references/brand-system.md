# TCZ dashboard brand system

Use this reference for web and product-interface decisions. The supplied assets remain the source of truth.

## Core palette

| Token | Value | Recommended use |
| --- | --- | --- |
| TCZ Orange | `#F05223` | Primary actions, active navigation, key highlights, selected data series |
| Black | `#000000` | Dark navigation, headings, high-emphasis text |
| Mid Gray | `#919499` | Secondary text, inactive states, supporting chart series |
| Light Gray | `#D4D4D4` | Borders, dividers, disabled surfaces |
| Warm Off-white | `#F5F0F0` | Main page background, subtle cards, quiet sections |

Use white where necessary for clean cards and contrast. Orange is an accent, not a background default. For long passages, use near-black text on white or off-white.

## Typography

- Family: Helvetica Now Display.
- Medium: page titles, section titles, KPI values, controls, and labels.
- Regular: body copy, table content, supporting text, and helper text.
- Keep headings compact and direct. Avoid forced uppercase for paragraphs or table content.
- Prefer tabular numerals when supported for KPI values and tables.

Suggested product scale:

| Role | Desktop size | Weight |
| --- | --- | --- |
| Page title | 32 to 40 px | Medium |
| Section title | 20 to 24 px | Medium |
| KPI value | 28 to 36 px | Medium |
| Body and table | 14 to 16 px | Regular |
| Caption | 12 to 13 px | Regular |

## Layout language

- Use a 12-column desktop grid and a 4-column mobile grid.
- Keep card radii restrained, around 10 to 14 px.
- Use crisp 1 px borders and minimal shadows.
- Favor asymmetric editorial moments only for overview or sign-in surfaces. Keep task-heavy screens systematic.
- A soft orange glow may appear on a hero or overview surface, inspired by the reference PDF. Do not use it behind dense text, forms, or tables.
- Avoid glossy gradients, glassmorphism, floating decorative shapes, or generic stock imagery.

## Logo handling

- Maintain aspect ratio and clear space.
- Prefer the full wordmark in persistent navigation or sign-in areas.
- On narrow mobile screens, allow the logo to reduce in width but never crop the wording.
- White logo belongs on black or sufficiently dark photography. Black logo belongs on white, off-white, or very light gray.

## Charts

Start with orange for the primary series, then black and gray. Use semantic colors only where the meaning is conventional and include a label or icon. Avoid using several similar orange shades for categories that must be distinguished precisely.
